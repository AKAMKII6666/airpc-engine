# 04. 调试器界面需求

路由：`/debugger`。浏览器只展示与发意图；模拟推进、可选文本 LLM 均在 **server**。

相关：[02](./02-运行时协议.md) · [10](./10-用户与存档.md) · [19](../技术设计文档/19-引擎宿主与会话模型.md) · [18](../技术设计文档/18-部署拓扑与BS架构.md) · [50](./50-对话与模型适配.md)

## 1. 进入流程（用户门禁）

```text
进入 /debugger
  → UserGate（全页或 Dialog：列表 / 新增 / 选择 / 删除；无密码）
  → 选定 userId → 加载 PlayerProfile
  → 进入调试台
```

与故事列表共用同一 `UserGate` 组件（见 [03](./03-编辑器界面需求.md)、[19](../技术设计文档/19-引擎宿主与会话模型.md)）。

## 2. 信息架构

```text
┌──────────────┬─────────────────────────────┬──────────────────┐
│ 模拟控制      │     Board / 时间线            │ 当前卡详情        │
│ · 当前用户    │  各角色 pending / active      │ · Composer 快照   │
│ · 起始卡      │  出口命中 / Free 管线         │ · 命中 promptScenes│
│ · 本地时间覆盖│  effect / Profile diff         │ · 工具策略        │
│ · 电话事件    │  log 切片                     │ · 出口+命中原因   │
│ · Outcome    │                               │ · 记忆摘要        │
│ · 时钟快进    │                               │                  │
├──────────────┴─────────────────────────────┴──────────────────┤
│ 底部：WET / Facts&knowledge / Lore / 校验警告 / 错误码提示        │
└──────────────────────────────────────────────────────────────┘
```

## 3. 基础流程

```text
选定 User → 加载 Profile（可重置）
  → 选起始卡 → simulate_start（读已保存 Content，冻结 frozenCard）
  → consumeOpeningFirstTurn（Host 幂等消费首句；direct 直接展示，llm_opening 走 server LLM）
  → 模拟电话事件 / 文本聊 / 手动 beats·flags
  → Story：ExitSelector → Effects
    Free：FreeCallPostPipeline（MemoryCommit；有候选则 ExitSelector）
  → save Profile；查看 diff 与 logs
  → 可选快进触发 schedule（触发点 = clock + minMs）
```

对话：v1 **Manual**；可接 **server 文本 LLM** 聊天 UI（`POST /api/debug/chat` **SSE** 推送一轮事件；可保留 `refreshStamp` 兜底重拉 snapshot）。首句开场必须先走 Host `consumeOpeningFirstTurn`：`emit_assistant_turn` 只展示 Host 已登记文本；`request_llm_opening` 才调用 server LLM；`already_emitted/skipped` 不重复补话术。Outcome：默认 Manual；高级区可「模型建议 Outcome」再确认（见 [19 §13](../技术设计文档/19-引擎宿主与会话模型.md)）。

**本地时间 / 场景组装：**

- `beginCall` 上报浏览器本地时间（或「固定本地时间」覆盖）→ `ComposeScene`  
- Composer / Prompt Trace 快照须显示：`callDirection`、本地时段 bucket、**matchedLayerIds**、最终 opening、provider 顺序与 first-turn 控制  
- 详见 [50](./50-对话与模型适配.md)

**过程话术模拟：** 按钮触发 `silence_timeout` / `call_duration_threshold` / `pre_hangup_hint`（引擎不计时）。

## 4. 与编辑器严格分离

- 调试器**不提供**改卡 / 改 package 的编辑 UI。
- 本通使用 `CallSession.frozenCard`；画布未保存草稿不影响本通。
- 发现问题：结束调试 → 回 `/packages/[packageId]/chapters/[chapterId]` 修改并保存 → 再进调试。

## 5. 必须显示

- Profile.Board diff；命中出口原因（static / dynamic）或 Free 管线步骤
- effect plan：`ok | skipped | failed` + plan.status
- RuntimeExitCandidate（可手动登记模拟 FC）
- world.facts / knowledge / memory 摘要；Lore 状态
- Composer / Prompt Trace 快照（受显示等级约束）；**命中的 promptScenes layer** 与 `debug.providerIds`
- Opening First-Turn 摘要：`firstTurnMode`、`firstTurnStatus`、`callerVisibility`、`llmContextPolicy.includeSoftContext/includeMemory/includeInertia`
- Opening Situation 摘要：`kind`、`control`、`priority`、`reason`、`tags`、是否覆盖首句
- **日志时间线**（Host ring + 可打开 jsonl 切片）
- 当前 `composeScene.localTime`（可覆盖）

### 5.1 Prompt Trace 边界

Prompt Trace 是观测面，不是运行状态机。Studio 可把 `RenderedPrompt.openingFirstTurn` 与 `[opening.situation]` block 投影成可读摘要；但业务行为必须来自 Host 返回的 `CallSession.openingFirstTurn` / `consumeOpeningFirstTurn` 结果。

| 字段 | 用途 |
|------|------|
| `providerIds` / `providerRows` | 核对 Prompt Provider 是否按预期生效 |
| `matchedLayerIds` | 核对卡级 / 角色级 promptScenes 命中 |
| `openingSituation` | 阅读 opening 来源与 first-turn 可见性 |
| `systemHardBlocks` / `softContextBlocks` | author 侧排障；playtest / 导出受隐私规则约束 |

**禁止：** Studio 为了“兼容”去解析 `[opening.situation]` 文本并自行决定 direct/LLM opening；旧快照文本解析仅允许作为展示兜底。

## 5.2 调试显示等级（隐私）

| 模式 | privateBrief |
|------|----------------|
| **author** | 可见 |
| **playtest** | 默认隐藏；可临时揭示 |
| **导出日志** | **不落** private 原文 |

## 6. 电话事件与 Outcome

接通结束、未接、占线、提前挂断、播放完成/跳过、重播、留言已听、回拨触发。预填 flags 后可改 beats，再结束通话。

## 6.1 语音留言信箱（最小调试路径）

与 [语音留言改造需求](../里程碑/v2.0/语音留言改造需求.md) §3.5–§3.6、Host 单测对齐；完整调试台大改可后续批。

| 能力 | 口径 |
|------|------|
| **信箱列表** | 读 `Profile.telephony.voicemails[]`（真源）；展示 status / text 摘要 / audioRef |
| **未读** | `deriveVoicemailHasUnread(telephony)`；可观察 `onVoicemailUnreadChanged` 回调（注入桩） |
| **听完** | 以 `entryMode=mailbox_open` + `cardKind=voicemail` 的 `beginCall` 起会话（`playback_only`）；播完 / 跳过 → Outcome（`voicemail_listened` / `playback_completed` / `playback_skipped`）→ ExitSelector → 该卡 exits |
| **禁止** | 按普通 `user_dial` / Board.pending 去「拨」留言卡；壳自播完只打 flag、绕过 Session 跑 exits |

## 7. 非目标

- 调试器内改卡或热重载本通 frozenCard
- 从 Prompt Trace / `[opening.situation]` 文本推断首句状态、绕过 `consumeOpeningFirstTurn` 自行拼 opening
- v1 强制 Realtime / 自动 Outcome
- 旧话机进程连接、完整时间旅行（P1）
