# 03. Studio 编辑器界面需求

Studio 编辑面：在 **B/S** 下由浏览器维护 UI；内容经 Next 门面进入引擎。**主入口是包列表**，再进入章列表与单章画布。

相关：[00](./00-文档索引.md) · [19-引擎宿主与会话模型](../技术设计文档/19-引擎宿主与会话模型.md) · [18](../技术设计文档/18-部署拓扑与BS架构.md) · [05](../技术设计文档/05-技术选型与工程边界.md)

**数据流**：浏览器编辑草稿 / 投影 → API 保存 → 引擎写 Content（JSON）。浏览器不直连磁盘业务文件、不持有 Profile 真源。

**UI**：基础组件库使用 **MUI**；画布使用 `@xyflow/react`。

## 1. 信息架构

| 台 | 路由 | 职责 |
|----|------|------|
| **首页框架** | `/` | Studio 总览；导航到各台 |
| 包列表 | `/packages` | 列出 StoryPackage（容器）；创建 = 新包 + 默认章骨架；删除/重命名 |
| 章列表 | `/packages/[packageId]` | 列出包内 Chapter；创建章；设定 `entryChapterId`（首章） |
| 章画布 | `/packages/[packageId]/chapters/[chapterId]` | 单章 CallCard 编辑（本文重点） |
| 角色 | `/characters` | CharacterDef、社交、dialable、FreeCallCard（v1 列表预览） |
| 世界 | `/world` | 当前用户 Profile：Lore／Facts／knowledge／schedule；UserGate；见 [40](./40-世界柱.md) |
| 资源 | `/assets` | 全局 `data/assets/` 元数据与文件登记；卡引用 `playbackClipId`；见 [14](./14-资源与媒体资产.md) |
| 用户 | `/users` | UserGate（选择/新建 Profile）；SaveGame 导出 |
| 调试 | `/debugger` | 见 [04](./04-调试器界面需求.md) |

顶栏 `StudioNav` 覆盖上表各台。

### 1.1 用户门禁（UserGate）

- **无密码**。组件 `UserGate`：列表 / 新增 / 选择；可放进 MUI Dialog。
- **进入章画布前**（`/packages/[packageId]/chapters/[chapterId]` 就绪态）硬挂：未选玩家不可操作画布；选定写入跨页 `studioSession`（sessionStorage）。
- **进入世界台**未选用户时弹出／引导 UserGate（与调试相同依赖：经历态在 Profile）。
- 故事**编辑逻辑与用户无关**（改 Content）；门禁仅为建立可调试 / 可预览的 Profile·Memory 上下文。
- 顶栏可显示当前用户并可切换；未选时调试类 / 首通提示词预览 API 返回 `USER_REQUIRED`（见 [19](../技术设计文档/19-引擎宿主与会话模型.md)）。

### 1.2 首通提示词预览（编辑期观测）

- **不是调试**：不建 `CallSession`，不改卡。
- 入口：故事卡属性面板与 FreeCallCard 编辑弹窗的「首通提示词预览」。
- 弹层选项：接通方式（玩家呼入 / 角色呼出）→ `callDirection`；时间点（本地小时 0–23）→ `promptScenes.localHourRange`。
- 「渲染提示词」经 Server `POST /api/prompt-preview`：Composer + Memory/Lore softExtras + tools（policy ∩ Registry）+ Adapter 同口径 system 拼接；只读展示（文本板 + Monaco JSON）。
- **必须**当前 Studio 玩家；无用户则弹 UserGate，禁止静默省略 Memory。

## 2. 包列表与章列表

### 2.0 包列表（`/packages`）

```text
┌─────────────────────────────────────────┐
│  故事包列表          [+ 创建故事包]          │
│  · 标题 / packageId / 校验状态           │
│  · 点击 → 进入章列表                      │
└─────────────────────────────────────────┘
```

创建故事包 = 新建目录 `data/storis-packages/<packageId>/`，写入 `package.conf.json`（含 `entryChapterId` 与默认首章 `chapters[]`）+ `chapters/<defaultChapterId>/` 骨架（`story.conf.json`（`cards: []`）+ `cards/` + `canvas.layout.json`）。

### 2.1 章列表（`/packages/[packageId]`）

```text
┌─────────────────────────────────────────┐
│  <包标题>  章列表      [+ 创建章]          │
│  · 标题 / chapterId / 校验状态           │
│  · entryChapterId 章置顶 + 金色描边       │
│  · 「设为入口章」改 package.conf         │
│  · 点击 → UserGate → 进入章画布           │
└─────────────────────────────────────────┘
```

- **首入口**：包级 `package.conf.json` 的 **`entryChapterId`**（实机载入整包后从此章开始）。**废弃**工作区级 `startupPackageId` / 首故事指针。
- 当前 `entryChapterId` 对应章在列表置顶并以金色描边展示；可一键改指针。
- 创建章 = 在 `chapters/<chapterId>/` 写入空 `story.conf.json` + `cards/` + `canvas.layout.json`，并登记进 `package.conf.json` 的 `chapters[]`。

## 4. 画布核心元素

| 元素 | 视觉 | 职责 |
|------|------|------|
| 角色泳道 | 每 participant 一条 lane | 拖卡改 `ownerAgentId` |
| Start | 唯一入口 | 指向 `entryCardId` |
| CallCard 节点 | free / story / system 样式 | 徽章：entryMode、interactionMode |
| Exit 端口 / 边 | 连到目标卡 | **UX 镜像**；真源仍是 `exits[].effects` |
| Effect | 默认右侧面板 | 复杂 plan 可不展开节点 |
| End | terminal 汇聚 | 可选 |

坐标与泳道序写入 **`canvas.layout.json` 旁车**；引擎运行忽略 layout。见 [19 §10](../技术设计文档/19-引擎宿主与会话模型.md)。

### 4.1 电话媒介徽章

由出口 effects 推导：呼入/外呼、playback、重播/留言/回拨等。

### 4.2 Studio v1 编辑器落地（增量）

| 能力 | 落点 |
|------|------|
| 左侧角色库 / Story 卡模板 | `StoryPalette`；`GET /api/characters` |
| Exit 连线 UX | 画布边投影自 `exits[].effects` 的 `attach_call_card`；连线/删边写回源卡 |
| 故事列表校验徽章 | `GET /api/packages` / 章列表附带 `validationStatus` |
| `story.conf.json` 在线编辑 | 属性面板「章配置」+ `PUT /api/packages/[packageId]/chapters/[chapterId]` |
| `package.conf.json` | 包列表 / 章列表「包配置」+ `PUT /api/packages/[packageId]` |

## 5. 主交互（v1）

1. 创建/编辑 CallCard → 添加 Exit → 连线到下一卡（生成 `attach_call_card`，可改）。
2. 选中 Exit → 面板编辑 condition、priority、effects。
3. **引荐/带话**：连到目标角色卡并写好目标卡 brief；不要独立 Relay 节点。
4. FreeCallCard 在角色库维护；静态 exits 可空；挂机走 FreeCallPostPipeline（有工具候选再 Exit）。默认全开 free 工具。
5. 真源：`package.conf.json` + `chapters/<chapterId>/story.conf.json` + `cards/*.s-card.json`；画布为投影。改 `cardId` = 重命名 `.s-card.json` 并改 conf 索引与其它卡引用（**卡 id 包内全局唯一**）。

## 6. 左侧库与属性面板

- 角色列表可跳转角色台。
- 每角色 FreeCallCard 可打开编辑（上下文/工具策略等；出口可空）。
- `playback_only` 锁定 deny_all tools。
- **场景层 `promptScenes`**：属性面板可增删层（方向 / 时段 / opening / tone）；校验禁止 patch `objective`/`forbidden`。详见 [01](./01-CallCard数据模型.md)、[50](./50-对话与模型适配.md)。

## 7. 角色台

信息架构与字段见 [11](./11-角色与社交.md)：identity（年龄/性别）、persona.systemPrompt、defaultPromptScenes、callFlowPrompts、social、Free 卡跳转。

## 8. 校验与导入导出

- `validateChapter(packageId, chapterId)` / `validatePackage(packageId)`（规则总表见 [08](./08-内容校验规则.md)）；error 阻断导出
- **交付物**：
  - **整包 storypack**（`.storypack.json` / `airpc.storypack.v1`）：含 `package.conf.json` + 全部 `chapters/`；打给实机时**一次只载入一整包**；首章由包内 `entryChapterId` 决定
  - **SaveGame**：玩家 Profile + Memory；与 Content 分开导出
- **废弃**：多包 `.contentpack.json` / `airpc.contentpack.v1` 及工作区 `startupPackageId` 管道（旧「内容包 = 多故事包串联」不再支持）
- `schemaVersion` 不兼容 → 拒载 Dialog（见 [17](../技术设计文档/17-版本迁移与兼容策略.md)、[19](../技术设计文档/19-引擎宿主与会话模型.md)）

## 9. 编辑体验

撤销/重做、多选删除为 P0；复制粘贴、自动布局、搜索为 P1。

## 10. 与调试器关系

- 编辑器**不**在通话中热更新正在调试的 Session（`frozenCard` 不变）。
- **保存 Content 可刷引擎包缓存**，但**不得**因此清空本通 Session / 已载 Profile（见技术设计 19）。
- 从画布「去调试」→ `/debugger`（再经 UserGate 若需要）→ 只读已保存内容。
- 调试中发现问题 → 退出调试 → 回本页改并保存 → 再调试。

## 11. 非目标

- 云协作、编辑器内强制 Realtime、Relay 专用节点
- 调试器内嵌改卡
