# 08. 内容校验规则

相关：[01](./01-CallCard数据模型.md) · [13](./13-工具与能力注册.md) · [14](./14-资源与媒体资产.md) · [19](../技术设计文档/19-引擎宿主与会话模型.md) · [03](./03-编辑器界面需求.md)

`validatePackage(packageId)` / `validateChapter(packageId, chapterId)` / `validateWorkspace()` 产出 `ValidationReport`：`{ errors[], warnings[] }`，每项含 `ruleId`、路径、文案。

- **`validatePackage`**：包容器（`package.conf.json`）、`entryChapterId` 有效、章索引一致、**包内 cardId 全局唯一**（跨章扫描）
- **`validateChapter`**：单章 `story.conf.json` + `cards/` + layout；规则同原单包校验，路径前缀为 `chapters/<chapterId>/`

**级别：** `error` 阻断导出与调试开跑（可配置）；`warning` 可导出，底栏提示。

## 1. 包 / 章 / 磁盘

| ruleId | 级别 | 说明 |
|--------|------|------|
| `PACKAGE_ENTRY_CHAPTER_UNKNOWN` | error | `package.conf.json` 的 `entryChapterId` 不在 `chapters[]` |
| `CHAPTER_INDEX_ORPHAN` | warning | 磁盘存在 `chapters/<id>/` 未登记进 `package.conf.json` |
| `CONF_CARD_FILE_MISSING` | error | 章 conf `cards[]` 有 cardId，无 `chapters/<chapterId>/cards/<id>.s-card.json` |
| `CARD_FILE_ORPHAN` | warning | 磁盘有 `.s-card.json` 未登记进该章 conf |
| `CARD_ID_DUP_PACKAGE` | error | 同一 `packageId` 下跨章 **cardId 重复**（卡 id 包内全局唯一） |
| `ENTRY_CARD_UNKNOWN` | error | 章 `entryCardId` 不在该章索引内 |
| `REFERENCED_AGENT_UNKNOWN` | error | 章内派生引用的 agentId（owner / effects / attach 等）不在角色库 |
| `PARTICIPANT_UNKNOWN` | warning | 遗留 `participants` 含不存在的 agentId（字段将忽略）；空数组或不写不报错 |
| `FREE_PACKAGE_SENTINEL` | error | 试图把 `__free__` 当真实故事包或章目录创建或 load |
| `END_STORY_NEXT_CHAPTER_UNKNOWN` | error | `end_story.next.chapterId` 不在本包 `chapters[]` |
| `END_STORY_NEXT_CROSS_PACKAGE` | error | `end_story.next` 引用包外 chapterId（禁止跨包串联） |
| `SCHEMA_UNSUPPORTED` | error | schemaVersion 不兼容（见 [17](../技术设计文档/17-版本迁移与兼容策略.md)） |
| `LAYOUT_IGNORED` | — | layout 旁车不参与运行校验（可存在） |

**路径 B（角色全局化）：** `participants` 可选、非白名单。`validateChapter` 对 `collectReferencedAgentIds` 派生集合做角色库存在性与 free/social 校验；`ownerAgentId` 不在遗留 `participants` 但在角色库 → **不得** error。

## 2. CallCard / 出口

| ruleId | 级别 | 说明 |
|--------|------|------|
| `PROMPT_SCENE_PATCH_HARD` | error | `promptScenes.patch` 含 objective/forbidden |
| `EXIT_EMPTY_STORY` | warning | story 卡完全无 exits；有任意一条出口即不再警告（不强制 failure/recovery 类别）。`cardKind=voicemail` 允许空出口，本规则不检 |
| `EFFECT_UNKNOWN` | error | 未知 effect 名 |
| `EFFECT_ID_DUP` | error | **章内** effect.id 重复 |
| `PLAYBACK_NO_ASSET` | error | playback_only 无 playbackClipId（**不含** `cardKind=voicemail`：留言靠物化，允许无 clip） |
| `OPENING_STORY_IN_CHARACTER_DEFAULT` | warning | 角色 `defaultPromptScenes` 疑似写入具体剧情 opening（如误会/打错电话/任务开场）；应移到 Story 卡或 Opening Provider |
| `OPENING_STORY_IN_FREE_CARD` | warning | Free 卡 `promptScenes` 疑似写入 Story 专属剧情 opening；Free 只承载日常接听/闲聊 |
| `OPENING_UNKNOWN_INBOUND_IDENTIFIES_USER` | warning | inbound unknown caller 的 opening 文案疑似直呼玩家、引用记忆或说已识别来电者；应交给 Opening First-Turn Gate |

## 2.1 语音留言（voicemail）

真源：[语音留言改造需求](../里程碑/v2.0/语音留言改造需求.md) §3.1–§3.3；实现见 `validation/package/voicemail.ts`。

| ruleId | 级别 | 说明 |
|--------|------|------|
| `VOICEMAIL_INTERACTION_MODE` | error | `cardKind=voicemail` 但 `interactionMode !== playback_only` |
| `VOICEMAIL_ENTRY_MODE` | error | `cardKind=voicemail` 但 `entryMode !== mailbox_open` |
| `VOICEMAIL_TOOL_POLICY` | error | `cardKind=voicemail` 但 toolPolicy 非 deny_all 等价 |
| `VOICEMAIL_ENTRY_KIND` | error | 非 voicemail 卡使用 `entryMode=mailbox_open` |
| `VOICEMAIL_CREATE_EFFECT` | error | 包内仍出现废弃 Effect `create_voicemail`（须改 `attach_call_card` / `schedule_call_card` 指向 voicemail 卡）；对 cardRaw 扫描，schema 亦拒识该 effect 名 |

## 3.1 Schedule / 外呼意图

落盘分工见 [01 §8.4](./01-CallCard数据模型.md)、[19 §3.4](../技术设计文档/19-引擎宿主与会话模型.md)。

| ruleId | 级别 | 说明 |
|--------|------|------|
| `SCHEDULE_ONCE_CARD_REQUIRED` | error | `schedule_call_card` 缺 `agentId`+`chapterId`+`cardId` |
| `SCHEDULE_RECURRING_CARD_REQUIRED` | error | `schedule_recurring_call` 缺 `scheduleCardId` 且缺 `cardId`+`chapterId` |

| `SCHEDULE_CARD_KIND` | error | recurring 目标不在 `characters/schedule-cards/`（或非法 `__free__` fallback）；**含**故事章内 `cardKind=schedule` 剧情节点冒充日常卡 |

## 4. 资产 / 角色

| ruleId | 级别 | 说明 |
|--------|------|------|
| `ASSET_UNKNOWN` | error | 引用不存在的 assetId |
| `ASSET_URI_MISSING` | error | uri 指向缺失文件 |
| `ASSET_KIND_MISMATCH` | warning | playback 引用了非音频类 |
| `ASSET_PACKAGE_INLINE` | warning | 包内出现完整 assets[] 内联（应迁全局库） |
| `SOCIAL_TARGET_UNKNOWN` | error | social.target 不在角色库 |
| `NARRATIVE_DIALABLE` | error | `isNarrativeOnly` 但 `dialable: true` |
| `NARRATIVE_NEEDS_NO_FREE` | warning | narrative-only 仍配置了 freeCardId |
| `FREE_CARD_MISSING` | error | 非 narrative-only 可通话角色缺 freeCardId 或文件 |
| `FREE_CARD_KIND` | error | free 卡 `cardKind !== "free"` |
| `CHARACTER_NOT_DIALABLE` | — | 运行时错误码，非包校验 |

## 5. 验收

- [x] error 阻断导出；点击问题可定位卡/章/文件（导出 API `hasBlockingErrors`；定位 UX 可增强）
- [x] golden 包 validate 无 error（含 `validatePackage` + 各章 `validateChapter`）
- [x] `__free__` 哨兵不可当包/章路径通过校验
- [x] `CARD_ID_DUP_PACKAGE` / `END_STORY_NEXT_*` 阻断非法章间跳转
- [x] `ASSET_URI_MISSING` 硬拦（meta 存在但 `uri` 文件缺失）；见 `VALIDATE_PACKAGE_ERROR_COVERAGE.covered`
- [x] warning 主路径进 coverage：`CARD_FILE_ORPHAN`／`EXIT_*`／`TOOL_INTRODUCE_GUARD`／`ASSET_KIND_MISMATCH`／`NARRATIVE_NEEDS_NO_FREE`／`ASSET_PACKAGE_INLINE`
- [x] Opening 内容校验可作为 warning：Free / 角色 default 不承载剧情 opening；unknown inbound 不提前识别玩家
