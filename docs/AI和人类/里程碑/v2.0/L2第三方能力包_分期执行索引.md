## 禁止事项（全程）

- 引擎内核 `readdir(plugins)`；引擎内裸目录名 `plugins/`
- 工作区根总 `enabledPackIds`；按流水线分子目录；`_multi/`
- 给作者 `data/` / SQLite / Host 私有 Map 路径
- 伪造无卡 CallSession；通话中热插包
- Client 执行包 Node 入口；Client import `@airpc/rpg-engine`
- 往 `createEngineHost` / beginCall / effect 中段堆特性
- L2 阶段做 ACL / 沙箱 / 签名

**代码任务默认 verify：** `npm run quality:engine` + `npm run quality:studio`。

## 可观测日志（全程必须）

| 事件 type | 时机 |
|-----------|------|
| `plugin.scan` | 完成一次扫描 |
| `plugin.load_ok` / `load_skipped` / `load_failed` | 单包结果 |
| `plugin.slot_contrib` | entry 挂槽成功 |
| `plugin.task_register` / `plugin.task_tick` | 任务 |
| `plugin.outbound_prepare` / `plugin.outbound_request` | 外呼 |
| `plugin.api_call` | 能力 API（抽样/debug） |

单包失败：跳过 + `plugin.load_failed`，默认不阻断内核。
