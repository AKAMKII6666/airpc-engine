# 特性插件作者手册（L2）

真源：[技术设计 25](../../技术设计文档/25-L2第三方能力包与SDK.md) · [执行索引](./L2第三方能力包_分期执行索引.md) · SDK `@airpc/pack-sdk`

## 1. 目录

```text
plugins/<id>/
  capability-packs.json   # 必填
  index.mjs               # 可选 main
  realtime/
  background/
  ui/
```

工作区根与 `data/` 并列。引擎**不**扫描本目录。

## 2. 清单

- `apiVersion` **必须为 1**（已冻结）
- `enabled` 为**唯一**开关（无工作区总表）
- 三大块：`realtime` / `background` / `ui`（可省略或 `enabled:false`）

管道项：`slot` + `entry`（相对包根）。

## 3. Entry 约定

模块可导出：

- 默认对象/数组（贡献本体）
- `default function (api) { return contribution }`
- `{ contribute(api) }` / `{ create(api) }`

加载期**不要**调用能力 API（Host 可能尚未就绪）；在钩子 `run` / `onTick` 中再调。

## 4. 能力 API

注入 `api: PluginCapabilityApi`（见 `@airpc/pack-sdk`）：users / characters / memory / llm / session / tasks / outbound。

**禁止**依赖 `data/`、SQLite、引擎内部路径。官方数据只经 API。

### 写接口当前范围（诚实口径）

- `users.update`：当前仅持久化 `nickname`（其它 patch 字段忽略）
- `characters.updateRuntime`：当前仅持久化 `unlocked`
- 更广档案/运行态字段属渐进扩展，勿假设任意 patch 键都会落盘

### session（当前接线）

- **可用：** `session.getSummary()`（宿主可注入摘要；默认可能为 `null`）
- **显式未接线（调用抛 `not_wired`，日志 `ok:false`）：** `subscribeEvents` / `injectSpeakable` / `reportToolResult` / `registerExitCandidate`  
  勿写成成功空操作；完整实时通道属后续产品化。

### memory.update

MemoryPort v1 仅 `insert`：`memory.update` **追加**新语义条，返回含 `appendedEntryId`、`inplaceUpdate: false`，不是原地改写。

## 5. UI

`ui.panels` 的 `entry` 指向静态 HTML（iframe）。Studio 经 `/api/plugins/panels` 与 `/api/plugins/<id>/assets/...` 托管。entry/资产路径经 `realpath`，禁止 symlink 逃出包根。

## 6. 通话内外

挂机 `call.afterHangup` → `api.tasks.register` → `tasks.onTick` → `outbound.requestCall`（须宿主正式外呼，禁无卡 Session）。外呼前会跑 `outbound.prepare`。

任务 id 按 `pluginId` 隔离：`cancel`/`get` 不能操作其它插件的同名 taskId。

## 7. 调试

调试器 Plugins Tab 或 `GET /api/plugins/status`：已加载包、失败原因、`scanRootError`、事件环。

## 8. 槽点接线债（apiVersion=1 冻结名仍有效）

下列槽点名已冻结，清单可写；Studio 当前若尚未挂入主链会记 `plugin.load_skipped` / `slot_not_wired:*`，**不阻断**其它槽：

- `tools.register` / `effects.register` / `dialogue.events`
- `schedule.topic`

已接线：`compose.providers`、`begin.softExtras`、`call.afterHangup`、`schedule.gates`、`commit.*`、`tasks.*`、`outbound.prepare` / `outbound.request`、三面板 UI。

与 L1 同名 `packId` / `hookId` / `gateId` / `taskId` 冲突时该 L2 包拒载并记 `plugin.load_failed`。
