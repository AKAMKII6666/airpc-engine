# Studio V2 · 路由与区域清单

> 对照基线：2026-09-09 代码盘点。  
> E2E 定位优先：**中文文案 + `aria-label`**（全仓无 `data-testid`）。  
> 壳层侧栏（非全屏页）：`aria-label="主导航"` → 首页 / 故事包 / 角色库 / 资源库 / 玩家配置 / 调试器 / 设置。  
> 全屏隐藏侧栏：章编辑器、`/stories/*`（瞬时 redirect）。

## 盘点备注（执行时核对）

1. `/packages/import` 与列表导入弹层勿重复记「导入成功」两次；深测以弹层为准，薄页只测引导。
