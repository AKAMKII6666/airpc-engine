# Studio V2 · 第二轮 E2E 用例矩阵（深测补缺）

> **状态：** 2026-09-10 已执行 → [报告/E2E报告-20260910.md](./报告/E2E报告-20260910.md)。  
> **前提：** 第一轮报告 [报告/E2E报告-20260909.md](./报告/E2E报告-20260909.md)；基线矩阵 [03](./03-用例矩阵.md) 仍有效。  
> **原则：** 只测不修；操作仅 UI；断言允许 Network / logs / debug-dto；禁 seed / 改盘造状态。  
> **范围：** 上一轮未深入 + P1 复测；**明确跳过**自动化做不了或成本过高的项。

## 1. 与第一轮关系

| 类型 | 处理 |
|------|------|
| 第一轮已 Pass 且无回归价值 | **不重跑**（NAV 全套、PKG-010 建包、UserGate、画布壳、章节进调试、free 首句、SSE 基本链路等） |
| 第一轮 Fail / 误报更正 | 本轮复测或按更正口径执行 |
| 第一轮 Blocked 且本轮可做 | 纳入下表深测 |
| 第一轮 Blocked 且仍测不了 | 见 §3「本轮跳过」 |

## 2. 本轮波次与出口

| 波次 | 内容 | 用例前缀 |
|------|------|----------|
| R2-A | 导出复测（先关 hydration overlay） | `R2-PKG-*` |
| R2-B | 编辑器深测（**点卡心，禁点删除 IconButton**） | `R2-ED-*` / `R2-PKG-051` |
| R2-C | 库写路径（临时实体前缀 `e2e_r2_`） | `R2-LIB-*` |
| R2-D | 调试器 FC + 挂机加深 + DBG-022 回归 | `R2-DBG-*` |
| R2-E | 设置扫尾 + 报告 | `R2-SET-*` |

**测完标准：** §4 全部有 Pass/Fail/Blocked；P1 复测有结论；报告落 `报告/E2E报告-YYYYMMDD.md`（建议日期用执行日）。
