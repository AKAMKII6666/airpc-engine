# Studio V2 · 全量 UI E2E 计划定稿

> **状态：** 口径已锁定（2026-09-09）；用例包已落盘，执行前可按波次开跑。  
> **性质：** Agent / 人工走测执行真源；**不是**产品验收签字。  
> **本轮原则：** 只测不修；问题进报告与意图台账。

## 1. 锁定口径

| 项 | 定稿 |
|----|------|
| 范围 | **全部路由深测**（见 [01](./01-路由与区域清单.md)）；不只冒烟 |

| 调试器基线 | 复用并扩展 [../08-调试器人工E2E清单.md](../08-调试器人工E2E清单.md) |

## 4. 环境

| 项 | 要求 |
|----|------|
| 入口 | Studio V2 本地（通常 `npm run dev` → 浏览器打开） |
| 用户 | 默认 `demo-user`；换用户必须写入报告 |
| LLM | `.env.local` / 环境变量 `AIRPC_LLM_API_KEY`；无 Key 时 DBG 依赖 LLM 的用例记 **Blocked**，不记 Fail |
| 浏览器 | 保持 Console + Network 可用 |
| 污染 | 不提交被测脏污的 `profile.save.json`、sqlite、logs；失败现场**保留** logs / debug-dto |

## 5. 判定与严重度

| 判定（意图台账） | 含义 |
|------------------|------|
| 一致 | 期望与现状相符 |
| 偏差 | 有需求，实现不符 |
| 缺失 | 需求有、界面无 |
| 多余 | 界面有、需求未写或明确不做 |
| 需求过时 | 代码合理，需求未更新 |
| 无法判定 | 缺前置 / 无 LLM / 环境阻断 |

| 严重度 | 含义 |
|--------|------|
| P0 | 阻断主创作/调试闭环 |
| P1 | 功能错误或关键链路断 |
| P2 | 次要功能 / 文案 / 空态 |
| P3 | 体验或 polish |

用例结果：`Pass` / `Fail` / `Blocked` / `Skipped`。

## 6. 明确不做

- 不修代码、不改产品需求正文（除非另开文档任务）
- 不做像素级视觉回归
- 不测旧 `apps/studio`、真电话壳、Realtime 硬件
- 不以 Vitest / `quality:*` 替代本 E2E
- 不宣称维护者产品体验验收已签

## 8. 每轮「测完」出口标准

1. [01](./01-路由与区域清单.md) 所列路由均有深测记录（`/stories/*` 仅测 redirect）
2. 已测 location 在 [02](./02-UI业务意图台账.md) 有行（期望可「需求未写」）
3. [03](./03-用例矩阵.md) 无「未跑且无理由」
4. 所有 P0 Fail / Blocked 已入报告
5. 报告文件落在 `报告/`，证据索引可回查

## 9. 失败取证最低集

- 用例 ID、步骤、时间、userId
- 界面现象（截图或文字）
- 相关 Network 请求路径 + 状态码 / 关键响应摘要
- 若涉及通话 / 挂机 / 外呼：`data/logs/`、`data/debug-dto/`、必要时 `data/post-call-jobs.json` 路径
- 关联 `INT-*` 意图 ID（若有）
