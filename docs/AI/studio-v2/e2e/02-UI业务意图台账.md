## 字段说明

| 字段 | 含义 |
|------|------|
| INT-ID | 意图主键 |
| locationId | 路由区域控件 |
| 需求期望 | 引自 UI 需求包 / 产品需求 / 08；无则「需求未写」 |
| 代码现状 | 本轮 UI 实测（含可见文案） |
| 判定 | 一致 / 偏差 / 缺失 / 多余 / 需求过时 / 无法判定 / **待测** |
| 严重度 | P0–P3；待测可空 |
| 证据 | 报告步骤、截图、Network、日志路径 |
| 关联用例 | `03` 中用例 ID |
